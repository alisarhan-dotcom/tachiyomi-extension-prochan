# Tachiyomi Prochan Extension

هذه الإضافة تسمح لك بقراءة المانجا من موقع [Prochan](https://prochan.net) مباشرة عبر تطبيق Tachiyomi أو Mihon.

## المميزات
- تصفح المانجا الأكثر شهرة.
- البحث عن المانجا.
- عرض تفاصيل المانجا (الوصف، المؤلف، التصنيف).
- عرض قائمة الفصول.
- قراءة الفصول بجودة عالية.

## كيفية الاستخدام
1. قم ببناء المشروع باستخدام Android Studio أو Gradle للحصول على ملف APK.
2. قم بتثبيت ملف APK على هاتفك الأندرويد.
3. افتح تطبيق Tachiyomi/Mihon وانتقل إلى قسم "Extensions".
4. ستجد "Prochan" مدرجاً ضمن الإضافات المثبتة.

## ملاحظات
